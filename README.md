# Queue Implementation in C

This repository contains a basic implementation of the Queue data structure in C, built from scratch for learning Data Structures and Algorithms.

## Functions Implemented
- Enqueue (Insertion)
- Dequeue (Deletion)
- Front / Peek
- isEmpty
- isFull

## Concepts Covered
- Queue using arrays
- FIFO (First In First Out)
- Overflow and Underflow conditions
- Basic queue operations logic

## Sample Operations
```c
enqueue();
dequeue();
front();
```
